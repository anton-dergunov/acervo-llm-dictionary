The whole vocabulary on every device, readable with no connection

Each device keeps a complete copy, so opening, searching and reading never wait for the server. A phone and a tablet show a word as cards to swipe; a wide window shows the page.
Reads offline, writes onlineA save is one round trip to the server and fails visibly without it. Only the server numbers a change, so there is nothing to merge.
Installed like an appOpen it in a browser, or install it: a web app (PWA) on Android and iOS, a native window on macOS that also lives in the menu bar.
A thousand words with their meanings, examples and study state take a few megabytes; pictures and recordings are fetched when first shown and then kept.
