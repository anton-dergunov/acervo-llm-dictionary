# Plans

What is still to do, including experiments designed and not yet run. A plan leaves this directory when
it is built — its reasoning folded into the topic document — or when it is no longer wanted. Git keeps
what it said.

**Core**

- [`capture-transports.md`](capture-transports.md) — getting a word in from every device.
- [`backups.md`](backups.md) — scheduled snapshots, an off-machine export, restore drills.
- [`provider-management.md`](provider-management.md) — providers in Settings, usage figures, an audit, a setup guide.

**Study material**

- [`anki.md`](anki.md) — review the cards, show how hard a word is, make Anki optional.
- [`loops-and-stories.md`](loops-and-stories.md) — choosing the words, favourites, level and length, listening hands-free.

**Words and languages**

- [`languages/language-support.md`](languages/language-support.md) — every feature in the languages people learn.
- [`languages/chinese.md`](languages/chinese.md) — the characters, the tones, and photos without spaces.

**Quality** — the research track: whether what the models write is right.

- [`quality/article-quality.md`](quality/article-quality.md) — the research programme for word articles.

- [`quality/translation-completeness-check.md`](quality/translation-completeness-check.md) — catching a translation that stopped early.
- [`quality/grounding-spike.md`](quality/grounding-spike.md) — whether a dictionary reference makes a better article.

**For other people**
