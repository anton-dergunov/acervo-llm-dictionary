# What every Acervo entry point needs.
#
# `httpx` is here because `acervo/client.py` is: it is the one HTTP client against the Acervo API, and
# a job or a consumer that writes the graph goes through it. It is also what the service calls a model
# and an online dictionary with, and what FastAPI's TestClient runs on — one HTTP library, not three.
#
# `litellm` is how `acervo/models/` reaches every provider but Cloudflare's image and audio
# endpoints. It is imported lazily, so an entry point that never calls a model never pays for it.
# `google-genai` is still here for `jobs/images/`, which plan 05 moves onto `models/`.
#
# `google-auth` is named rather than left to arrive with LiteLLM: `models/google_tts.py` imports it
# directly to authenticate Cloud Text-to-Speech, so it is this package's own dependency and must not
# disappear when another one stops needing it.
# `babel` is CLDR read from Python: which locales are close (`es-AR` and `es-US` share
# `es-419`), which locale a bare language means, and what to call a country. `models/locales.py`
# is its one reader, and choosing a voice for an accent is the reason. `langcodes` (with its
# `language-data`) carries CLDR's speaker counts, which Babel does not, so the accents a language is
# offered come most-spoken first. Both MIT.
